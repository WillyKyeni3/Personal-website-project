Green Nexus — Sustainability Platform & AI Waste Scanner

Full-stack sustainability web application combining an AI-powered waste classification scanner with practical disposal guidance and user engagement workflows.

Full-Stack Web AI Vision Classification REST API Responsive UI

01 / Problem & Constraints

Recycling and waste sorting break down at the point of disposal because everyday users are unsure which materials are recyclable, compostable, or hazardous. The application needed a fast, mobile-friendly scanning interface that turns a quick photo into immediate disposal instructions.

02 / Architecture & Stack Decisions

Designed a decoupled client-server flow where the frontend handles camera/image upload compression and renders structured classification cards returned by the AI inference endpoint.

[Mobile / Web Camera Input] → [Client Image Optimization] → [AI Classification API] → [Category + Disposal Rules + Impact Tracking]

03 / Engineering & Implementation Highlights

  • Built a responsive mobile-first scanner interface so users can capture or upload waste items cleanly on low-bandwidth connections.
  • Mapped raw model classification outputs to human-readable waste categories and local disposal recommendations.
  • Designed clear visual feedback states (loading, confidence classification, and fallback guidance) to keep the user experience predictable.

04 / Outcome

Delivered an end-to-end sustainability prototype demonstrating applied computer vision, clean API integration, and accessible user-centered design.
